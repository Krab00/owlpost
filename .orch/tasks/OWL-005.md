## Description
Implement `tls.rs` per `docs/architecture.md §4` and `docs/technical-design.md §7`. From the
ed25519 identity build a self-signed X.509 certificate with rcgen (Ed25519 signature
algorithm). Provide `server_config(identity, book, allow_unpinned_for_card: bool) ->
rustls::ServerConfig` with a custom `ClientCertVerifier` that accepts a client certificate iff
its SubjectPublicKeyInfo public key equals a pubkey in the ContactBook (and records the
resulting fingerprint for handlers), or, when configured, accepts *no* client certificate for
card-only requests; and `client_config(identity, expected_pubkey: Option<PubKey>) ->
rustls::ClientConfig` with a `ServerCertVerifier` that pins the server's public key (None =
unpinned, used only by `owl add`). Expose `peer_fingerprint_from_cert(&CertificateDer)`.
This is the riskiest piece of the project: do it first, keep it under ~200 lines, document any
rustls `danger` API used.
