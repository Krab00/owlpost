## Description
Implement the pull half of `daemon.rs` per `docs/architecture.md §3.5`. Every
`config.pull_interval_secs` the daemon groups `asks/` records by responder fingerprint, and for
each responder with at least one open ask calls `GET /v1/outbox` on the first reachable
endpoint. For each returned envelope: verify the signature against the responder's pinned key,
check `in_reply_to` matches an open ask, store the answer in `inbox/` with state `pending`,
update the asker cache, move the ask to `done/`, ack, and emit the daemon's `AnswerIngested`
event, which `notify.rs` (OWL-012) turns into the desktop notification. Responders that fail to
connect are recorded in an in-memory liveness cache (`last_probe`, `ok`) and skipped for 60 s,
capped at one pull interval minus one second (so the re-probe never depends on tick jitter; a
1 s interval re-probes an offline peer on every loop, as AC4 requires). Outbox
entries older than `outbox_ttl_days` are expired to `done/` with state `expired` by the
responder's daemon on each loop. `owl doctor` reports the daemon's last pull time from
`$OWLPOST_HOME/daemon.status` (JSON written each loop).

## Acceptance criteria
- [ ] AC1: integration test `tests/pull.rs::answer_is_pulled_and_acked` with `pull_interval_secs = 1`: A has an open ask to B; B's outbox holds a signed answer for it; within 5 s A's inbox has the answer (state pending, seen false), A's cache has it, A's `asks/` is empty, and B's outbox record is in `done/` (modality: test)
- [ ] AC2: integration test `tests/pull.rs::forged_answer_is_dropped` places an answer in B's outbox signed by a key that is not B's and asserts A never ingests it and logs a warning (modality: test)
- [ ] AC3: integration test `tests/pull.rs::unrelated_answer_is_ignored` places an answer whose `in_reply_to` matches no open ask and asserts it is not ingested and not acked (modality: test)
- [ ] AC4: integration test `tests/pull.rs::offline_responder_is_skipped_then_retried` points B at a closed port for the first 3 s and then starts B; A ingests the answer within 10 s (modality: test)
- [ ] AC5: integration test `tests/pull.rs::outbox_ttl_expires` with `outbox_ttl_days = 0` and a record dated yesterday asserts it moves to `done/` with state `expired` on the first loop (modality: test)
- [ ] AC6: `daemon.status` JSON contains `last_pull_at`, `open_asks`, `peers_probed` after one loop (modality: data)
