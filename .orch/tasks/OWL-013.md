## Description
Create `plugins/claude-code/` per `docs/concept.md` (Harness adapters) and
`docs/architecture.md §3.3, §3.6`. `.claude-plugin/plugin.json` (name `owlpost`, version from
Cargo). `hooks/hooks.json`: `SessionStart`, `UserPromptSubmit` and `PostToolUse` each run
`owl inbox --count --format claude` (timeout 5 s; the hook must be a no-op when `owl` is not on
PATH — wrap in a tiny shell script that exits 0 silently). `skills/owlpost/SKILL.md`: when to
ask a peer (the user names a colleague, or asks about code whose blame points at a contact),
how to run `owl ask` (prefer `--file` candidates, always show the human the chosen peer before
sending), how to react to the injected counter (offer to show the inbox, never dump content
unasked), the answer loop (`owl inbox` → `owl show` → `owl draft` → show the draft verbatim →
`owl send`/`owl edit`/`owl reject` only on explicit human approval), and the memory rule: when
the human accepts an answer, save it to memory with provenance `owlpost:<peer>:<question id>`
and the date. Slash commands `commands/inbox.md` (`/owlpost:inbox` → list and offer actions),
`commands/ask.md` (`/owlpost:ask <peer> <path> <question>`), `commands/history.md`. A README in
the plugin dir with install steps (`/plugin marketplace add` + `/plugin install`) and the
requirement that `owl daemon` is installed.
