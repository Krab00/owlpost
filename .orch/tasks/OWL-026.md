## Description
Finding from 2026-09-06: a fresh session got the `SessionStart` injection
`owlpost: arm the inbox watch (see /owlpost:watch)`, the first prompt was `/owlpost:watch status`,
and the watch was never armed. Claude answered "not running; default on" and moved on. Two
causes: the injected sentence is a pointer ("see /owlpost:watch"), so on a first turn that is
itself a slash command the pointer is treated as ambient context and dropped; and
`/owlpost:watch status` only reports, so the one command that would notice "default on but not
running" does nothing about it.

Fix, smallest that closes both gaps:

- **Self-contained arm instruction.** `ARM_SENTENCE` (`src/cli/inbox.rs`) becomes an
  imperative that carries everything needed, so no lookup is required on the first turn:
  `owlpost: before handling this prompt, arm the inbox watch once: Monitor(persistent: true,
  description "owlpost inbox", command: <the poll script from commands/watch.md verbatim>).`
  Exact wording is the implementer's, but it must (a) start with `owlpost: before handling this
  prompt`, (b) contain `description "owlpost inbox"`, `persistent: true` and the full poll
  script one-liner (`prev=""; while true; do cur=$(owl inbox --count --format plain ...`), and
  (c) still end the `--session-start` line only (no other hook event carries it). The JSON
  escaping in `--format claude` must stay valid (the script contains `"` and `$`).
- **`/owlpost:watch status` arms when it should.** `commands/watch.md` `status`: after
  reporting, if no "owlpost inbox" Monitor is running in this session and the stored default is
  on, arm it (same Monitor call as `on`) and say `owlpost watch: running; default on` instead.
  `off` and `on` unchanged.
- **Skill.** SKILL.md "Live watch" says the sentence is self-contained and imperative: arm on
  the first turn even when that turn is a slash command; `/owlpost:watch status` arms when
  default is on and nothing runs.
- **Docs**: README watch paragraph and design doc §11 (or wherever OWL-023 documented the
  injection) quote the new sentence prefix. Tests in `tests/plugin.rs` (`ARM`, `CLAUDE_ARM_*`
  constants) and `src/cli/inbox.rs` unit tests updated to the new literal; `tests/docs.rs`
  pins the `status` arming line in `commands/watch.md`.

Out of scope: a hook that detects a running Monitor (hooks cannot see session state);
Codex/Kimi.
