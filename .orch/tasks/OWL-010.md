## Description
Implement the inbox commands per `docs/technical-design.md §8–§9` and `docs/architecture.md
§3.3–§3.4`. `owl inbox` lists inbox records (id, from name, type, state, path, age) and marks
them seen; `--new` only unseen; `--all` includes seen; `--count` prints the unseen count;
`--format plain|claude|codex|kimi` with `--count` emits exactly the injection shapes from §9 and
**empty output with exit 0 when the count is 0**. `owl show <id|all>` prints the full question
or answer (and the draft if present) and marks seen. `owl draft <id>` runs the OWL-009 runner,
stores the draft on the record (state `drafted`), prints it with a redaction summary.
`owl edit <id>` opens the draft in `$EDITOR` and stores the result. `owl send <id>` builds the
answer payload (`in_reply_to`, `harness`, `redactions`, `cached=false`), signs it, writes it to
`outbox/`, moves the question to `done/` (state `answered`), updates the responder cache.
`owl reject <id>` moves to `done/` (state `rejected`). `owl history` lists `done/` with filters
`--peer`, `--path <glob>`, `--since <RFC3339|Nd>`. `--json` on all of them.

## Acceptance criteria
- [ ] AC1: integration test `tests/inbox.rs::count_and_formats` with two unseen questions asserts `owl inbox --count` prints `2`, `--count --format claude` prints a single line of JSON with `hookSpecificOutput.hookEventName == "UserPromptSubmit"` and `additionalContext` starting with `owlpost: 2 new questions`, and with zero unseen prints nothing and exits 0 (modality: test)
- [ ] AC2: integration test `tests/inbox.rs::listing_marks_seen` asserts `owl inbox` shows both, a second `owl inbox --count` prints `0`, and `owl inbox --new` prints nothing while `--all` still lists both (modality: test)
- [ ] AC3: integration test `tests/inbox.rs::draft_send_moves_records` runs `owl draft <id>` with the fake harness, asserts state `drafted` and the printed draft contains `[redacted]`; then `owl send <id>` creates an outbox envelope whose signature verifies against the responder's key, with `in_reply_to == <id>` and `redactions == 1`, the question is in `done/` with state `answered`, and the responder cache holds the answer under the question hash (modality: test)
- [ ] AC4: integration test `tests/inbox.rs::edit_replaces_draft` with `EDITOR` set to a script that appends `EDITED` asserts the stored draft ends with `EDITED` and `send` ships the edited text (modality: test)
- [ ] AC5: integration test `tests/inbox.rs::reject_and_history` rejects one record and asserts `owl history --json` lists it with state `rejected`, `--peer <name>` filters correctly, and `--since 1d` includes it (modality: test)
- [ ] AC6: `owl draft <id>` on a record in state `consent` exits 1 with a message containing `owl allow` (modality: test)
- [ ] AC7: `owl send <id>` without a draft exits 1 with a message containing `owl draft` (modality: test)
