## Description
Implement `runner.rs` per `docs/technical-design.md §10` and `§3` (`harnesses`, `projects`).
`Runner::draft(config, question_payload) -> Draft { text, harness, redactions, status }`: pick
the harness (`--harness` override, else `config.responder.harness`; refuse a template with
`enabled == false` naming `disabled_reason`), resolve the working directory from
`config.projects[project]` (error `unknown project` otherwise), build the §10 prompt (scope
sentence reflects `responder.scope`; the question is quoted inside triple quotes and never
interpolated into instructions), substitute `{prompt}` or write `{prompt_file}`, spawn with the
template `env`, `OWLPOST_RESPONDER=1`, capture stdout/stderr, enforce `timeout_secs`, extract
the answer via `answer_path` (`raw`, `result`, `last_message`, `last_text`), run the redaction
regexes (replace with `[redacted]`, count), and return. Ship
`tests/fixtures/fake-harness.sh`: prints a JSON-free canned answer containing the line
`api_key = sk-test-123456` and echoes argv + stdin to `$FAKE_HARNESS_LOG`; a `FAKE_SLEEP` env
makes it sleep for timeout tests. Ship `scripts/opencode-agent.json` with the `owl-readonly`
agent definition (tools write/edit/bash disabled).
