## Description
Ship the one-command install per `docs/concept.md` (Rollout). GitHub Actions `release.yml`
triggered by a `v*` tag: builds `owl` for `aarch64-apple-darwin`, `x86_64-apple-darwin`,
`x86_64-unknown-linux-gnu`, `aarch64-unknown-linux-gnu` (cargo-zigbuild or cross), attaches
tarballs plus `SHA256SUMS` to a GitHub release. `scripts/install.sh`: detects OS/arch,
downloads the latest release asset, verifies the checksum, installs to `~/.local/bin/owl`
(or `/usr/local/bin` with `--system`), prints next steps (`owl init`, `owl install`,
`owl contact export`). README quickstart: install → `owl init` → `owl install` → export the peer
file → PR into `.agents/peers/` → `owl doctor` → first `owl ask`. `docs/pilot.md`: onboarding
checklist for the 4–5 pilot users, the `CODEOWNERS` line and admin fingerprint-check procedure,
the metrics to collect (from `owl history --json`), and the kill criteria.
