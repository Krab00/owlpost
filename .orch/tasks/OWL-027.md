## Description
User request 2026-09-06: when a message from a peer arrives (watch event, hook counter, a
question or answer shown by `/owlpost:inbox`), display it with an owl icon and in an orange
frame so it stands out from the rest of the conversation.

Claude Code renders assistant text as terminal markdown: no colours, no borders. The frame is
therefore built from characters. Convention (docs only, plus the hook counter line):

- **Counter and watch lines** get the icon: `🦉 owlpost: 1 new question (Krzysztof 1). ...`
  The `🦉 ` prefix is added in Rust to every `--format claude` and `--format plain` counter
  sentence (`src/cli/inbox.rs`), not to the arm sentence and not to the `- <peer> ...` record
  lines. The watch script emits the plain line, so watch events carry the icon for free.
- **Framed message block**, used by `/owlpost:inbox` for every question and answer it prints,
  and by the "Showing messages" table rule when a single message is shown outside a table:

  ```
  🟧🟧🟧🟧🟧🟧🟧🟧🟧🟧🟧🟧🟧🟧🟧🟧
  🦉 **Krzysztof Abramczyk** · 09:08 · github.com/Krab00/owlpost · whole repository
  ```text
  Jaki masz ostatni commit u Siebie?
  ```
  🟧🟧🟧🟧🟧🟧🟧🟧🟧🟧🟧🟧🟧🟧🟧🟧
  ```

  Top and bottom line: 16 × `🟧`. Header: `🦉 **<peer>** · HH:MM · <project> · <path or
  "whole repository">` (fingerprint on the header for `consent` records). Body: the text
  verbatim in a code block, exactly as today. Drafts (our own text) are NOT framed: they keep
  the plain code block, so the orange frame always means "from a peer".
- **Where it is written**: SKILL.md gets a "Framed message" subsection under "Showing
  messages" with the block above; `commands/inbox.md` steps 2, 3 and 5 say "print the framed
  message block (see the skill)" instead of "in a code block with peer name..."; `commands/watch.md`
  event line example gains the icon; the answers table (step 5) keeps the per-peer colour
  marker rule and is not framed.
- Tests: `tests/plugin.rs` pins the `🦉 ` prefix on the counter output (plain and claude
  formats, zero-count still prints nothing) and the SKILL/inbox/watch literals; `tests/docs.rs`
  pins the README line that mentions the frame.

Out of scope: real ANSI colour (Claude Code strips it), Codex/Kimi output formats.
