## Description
Create the Rust crate `owlpost` with binary `owl` as specified in `docs/technical-design.md §1–§3`.
Clap skeleton with every subcommand from §9 present (unimplemented ones print
`not implemented yet` and exit 1). `config.rs` resolves `$OWLPOST_HOME` (default
`~/.config/owlpost`, overridable by `--home`), loads `config.json` with the §3 defaults when the
file is missing, and round-trips it. GitHub Actions workflow running build, test, clippy
(`-D warnings`) and fmt on `ubuntu-latest` and `macos-latest`. `.gitignore`, `rust-toolchain.toml`
(stable), `Cargo.lock` committed.

## Acceptance criteria
- [ ] AC1: `cargo build` succeeds and `target/debug/owl --version` prints `owl 0.1.0` (modality: test)
- [ ] AC2: `owl --help` lists all subcommands from technical-design §9: init, whoami, card, contact, add, allow, deny, ask, inbox, show, draft, edit, send, reject, history, watch, daemon, install, uninstall, doctor (modality: test)
- [ ] AC3: `owl --home <tempdir> whoami` on an empty home exits 1 with a message containing `owl init` (modality: test)
- [ ] AC4: unit test `config::tests::defaults_when_missing` asserts `listen == "0.0.0.0:7411"`, `pull_interval_secs == 60`, `rate_limit_per_peer_per_hour == 20`, and `harnesses` contains keys claude, codex, opencode, kimi, fake with kimi `enabled == false` (modality: test)
- [ ] AC5: unit test `config::tests::roundtrip` writes a Config to a temp home, reloads it, and asserts equality (modality: test)
- [ ] AC6: `cargo clippy --all-targets -- -D warnings` and `cargo fmt --check` pass (modality: test)
- [ ] AC7: `.github/workflows/ci.yml` exists with a matrix of ubuntu-latest and macos-latest running build, test, clippy, fmt (modality: data)
