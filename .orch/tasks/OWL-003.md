## Description
Implement `envelope.rs` and `spool.rs` per `docs/technical-design.md §6 and §8`.

Envelope: `Payload` (v, id UUIDv7, type question|answer, from, to, ts RFC3339, in_reply_to,
body enum QuestionBody|AnswerBody) with `to_signed_bytes()` producing the exact bytes to sign,
`Envelope { raw: String, sig: String }`, `Envelope::sign(payload, identity)`,
`Envelope::verify(&self, pubkey) -> Result<Payload>` that verifies the raw bytes before
parsing, and `question_hash(project, path, question)` with the §6 normalisation. Replay checks:
`is_fresh(ts, now, 300s)` and a `SeenIds` window persisted to `$OWLPOST_HOME/seen-ids.txt`.

Spool: directories `inbox/ outbox/ asks/ done/ cache/` under `$OWLPOST_HOME/spool`, record type
`{ raw, sig, state, seen, received_at, draft, meta }`, atomic writes (temp file + rename),
`put`, `get`, `list(dir, filter)`, `set_state`, `mark_seen`, `move_to(done)`, `count_unseen`,
and cache get/put by question hash.

## Acceptance criteria
- [ ] AC1: unit test `envelope::tests::sign_then_verify` builds a question payload, signs it, verifies with the right pubkey, and asserts verification fails with another key and after modifying one character of `raw` (modality: test)
- [ ] AC2: unit test `envelope::tests::question_hash_normalises` asserts `"  Why  X? "` and `"why x?"` hash equal and differ from `"why y?"`, and the hex is 64 chars (modality: test)
- [ ] AC3: unit test `envelope::tests::replay_window` asserts a payload 301 s old is rejected, 299 s accepted, and a second `SeenIds::insert` of the same id returns false, surviving a save/load cycle (modality: test)
- [ ] AC4: integration test `tests/spool.rs::atomic_put_leaves_no_temp_files` puts 100 records and asserts no `*.tmp` files remain and all 100 are listed (modality: test)
- [ ] AC5: integration test `tests/spool.rs::state_transitions` walks consent → pending → drafted → done and asserts `count_unseen` goes 1 → 0 after `mark_seen` (modality: test)
- [ ] AC6: integration test `tests/spool.rs::cache_roundtrip` stores an answer under a hash and reads it back; a different hash returns None (modality: test)
- [ ] AC7: JSON produced for a question payload matches the field names and order in technical-design §6 exactly (golden test with a fixed UUID and timestamp) (modality: test)
