## Description
Implement `notify.rs`, `cli/install.rs`, `cli/watch.rs`, `cli/doctor.rs` per
`docs/technical-design.md §9, §11`. `notify(kind, peer_name, path)` runs `osascript` on macOS
or `notify-send` on Linux when `config.notify` is true and the binary exists; the text never
contains the question or answer body; `OWLPOST_NOTIFY_CMD` overrides the command (tests point it
at a script that appends to a file). The daemon calls it on question arrival (OWL-006 hook) and
answer ingestion (OWL-008 hook). `owl install` writes `~/Library/LaunchAgents/dev.owlpost.owl.plist`
(macOS) or `~/.config/systemd/user/owlpost.service` (Linux) running `owl daemon` with the
current `--home`, loads/enables it, and prints status; `--dry-run` prints the unit to stdout
and writes nothing; `owl uninstall` reverses it. `owl watch [--id <id>] [--timeout <secs>]`
polls the spool every 500 ms and exits 0 printing the record id when a matching unseen inbox
record appears, exit 4 on timeout. `owl doctor` checks: key present, config parses, each
endpoint's host resolves, configured harness binaries are on PATH, daemon reachable at
`daemon.addr` (card fetch), last pull age; prints one line per check with ok/warn/fail and exits
1 if any check fails.

- [ ] AC3: `owl --home <tmp> install --dry-run` prints a plist on macOS / a systemd unit on Linux containing the absolute `owl` path, `daemon`, and `--home <tmp>`, and creates no file (modality: test)
- [ ] AC4: integration test `tests/watch.rs::watch_returns_on_arrival` starts `owl watch --timeout 10`, writes an inbox record after 1 s, and asserts exit 0 with the id on stdout within 3 s; `--id <other>` keeps waiting and exits 4 at the deadline (modality: test)
- [ ] AC5: integration test `tests/doctor.rs::doctor_reports_each_check` with a running daemon asserts exit 0 and lines for key, config, endpoints, harness, daemon, pull; with the daemon stopped asserts exit 1 and a `fail` on the daemon line (modality: test)
- [ ] AC6: `owl install` and `owl uninstall` are covered by a test that runs them with `HOME` pointed at a temp dir on the current OS and asserts the unit file is created and removed (loading may be skipped when `OWLPOST_INSTALL_NO_LOAD=1`) (modality: test)
